# Usage

Start a task with your agent, return to it later, and continue through the channel
that suits you. This guide covers everyday use once your server and
[tentacles](../tentacles/index.md) are connected.

## Try your first conversation

1. Open Trunkline and start a new conversation, or message your agent in a
   connected channel. In a shared channel, mention the bot.
2. Describe the result you want. For example: “Help me compare these ideas and
   turn the strongest one into a plan.”
3. Answer any questions or approval requests, then continue in the same thread.

You can also keep working in your agent's own app, editor or terminal. With the
client connected, those sessions appear in Octomate's history too.
[Start a conversation](agents/sessions.md) covers both ways of working.
