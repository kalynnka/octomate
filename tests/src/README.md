# Test source assets

Drop a real image here (any `*.png` / `*.jpg` / `*.jpeg` / `*.gif` / `*.webp`)
and the `@trigger` live-replay tests will upload it as the showcase's image
segment, so it is actually visible in the IM client. With no image present the
tests fall back to a generated 1x1 PNG (machine-valid, but too small to
eyeball).
